# 心房搜查令

2024 级数据科学与大数据技术班参加第十四届校园心理情景剧大赛的原创作品。

## 讲的是个什么故事

赵学衡是中医药大学大三的学生。作息严苛，桌面干净，打卡率 100%，搁谁看都是个自律模范。
可他柜子深处锁着一堆东西：没拆封的网课、一页没翻的考研资料、打满勾的日程本，
还有医务室一张张开出来的助眠药单。从老家带出来的那种匮乏感，让他一边拼命囤，
一边死活不肯承认自己还没准备好。

室友兼班级心理委员郝朋拿着一张《心房关怀通行证》，打着搜查的旗号，
一层层把柜门撬开。中间有对峙，有崩溃，也有四个年轻人互相接住的那一刻。

## 想说的是

剧本借了《人民的名义》里搜查那段做戏剧框架，把反腐搜查转化为潜意识心房搜查，
直击当代大学生的“学术与资料囤积障碍”（Hoarding Disorder）与“冒名顶替综合征”（Impostor Syndrome）——那种总觉得别人随时会看穿自己的害怕与内耗。

后半段紧密结合中医药大学学科背景，接入中医“思则气结、土壅木郁”的病机理论与“五音疗疾”传统智慧，
用一支紫竹笛吹奏古曲《清心引》把情绪慢慢引回来，最后落在《黄帝内经·素问》那句：
“恬淡虚无，真气从之；精神内守，病安从来！”

## 八幕分镜

1. **宿舍暗潮** · 深夜孤光下的寡淡清汤面与强装自律
2. **门口对峙** · 走廊冷白强光斜切入室，手提公文夹的心理搜查官
3. **宿舍交锋** · 100%打卡神话与医务室助眠药单残酷并置
4. **暗室铁柜** · 三把黄铜大锁，死守柜门的赵学衡
5. **书籍雪崩** · 柜门洞开，成山未拆封资料与考研讲义海啸塌下
6. **破防与接纳** · 甩开安慰的应激，递到面前的那杯温热陈皮麦冬茶
7. **笛声晨光** · 紫竹笛清越吹响《清心引》，苛刻打卡清单被撕碎成蝶
8. **尾声谢幕** · 四人并肩深情鞠躬，大屏金句定格与掌声齐鸣

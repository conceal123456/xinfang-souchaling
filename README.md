# 心房搜查令

2024 级数据科学与大数据技术班参加第十四届校园心理剧大赛的作品。

## 讲的是个什么故事

赵学衡是中医药大学大三的学生。作息严苛，桌面干净，打卡率 100%，搁谁看都是个自律模范。
可他柜子深处锁着一堆东西：没拆封的网课、一页没翻的考研资料、打满勾的日程本，
还有医务室一张张开出来的助眠药单。从老家带出来的那种匮乏感，让他一边拼命囤，
一边死活不肯承认自己还没准备好。

室友兼班级心理委员郝朋拿着一张《心房关怀通行证》，打着搜查的旗号，
一层层把柜门撬开。中间有对峙，有崩溃，也有四个年轻人互相接住的那一刻。

## 想说的是

剧本借了《人民的名义》里搜查那段做框架，把反腐搜查换成了潜意识搜查，
写的是学术囤积和冒名顶替综合征——那种总觉得别人随时会看穿自己的害怕。

后半段接上中医的思则气结、土壅木郁，和五音疗疾的老办法，
用一支紫竹笛把情绪慢慢引回来，最后落在《黄帝内经》那句：
恬淡虚无，真气从之；精神内守，病安从来。

## 八幕

1. 宿舍暗潮 · 深夜孤光下的寡淡清汤面
2. 门口对峙 · 走廊白光倾泻，手提公文夹的心理搜查官
3. 宿舍交锋 · 打卡神话和助眠药单摆在一起
4. 暗室铁柜 · 三把黄铜大锁，和死守柜门的赵学衡
5. 书籍雪崩 · 柜门洞开，一页没看的资料塌下来
6. 破防与接纳 · 甩开安慰的应激，和递到面前的那杯温茶
7. 笛声晨光 · 紫竹笛响起来，苛刻的清单被撕碎
8. 尾声谢幕 · 四人并肩鞠躬，大屏打出黄帝内经
